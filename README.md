# Grupo X Films - Sitio web estático

Sitio web multipágina (12 páginas) para una productora de cine, creado desde cero con HTML, CSS y JavaScript puro.

## Requisitos

- [Visual Studio Code](https://code.visualstudio.com/) instalado.
- Extensión recomendada: **Live Server**.
- Navegador moderno (Chrome, Edge, Firefox).

## Cómo ejecutarlo

1. Abrí la carpeta del proyecto en VS Code.
2. Instalá la extensión **Live Server** (si todavía no la tenés).
3. Hacé click derecho en `index.html` y elegí **Open with Live Server**.

También podés correrlo con Python:

```bash
python3 -m http.server 8080
```

y abrir `http://localhost:8080`.

## Estructura

- `index.html` y 11 páginas adicionales.
- `assets/css/styles.css` estilos globales.
- `assets/js/main.js` lógica común del sitio.
- `assets/js/games.js` mini-juegos interactivos.
